# Changelog

All notable project changes will be documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project intends to use semantic versioning after the initial public release.

## [1.0.0] - 2026-08-14

### Added

- Private-by-default Qwen3/llama.cpp workstation application with local SQLite history
- Optional search-grounded responses with visible sources and bounded public-page retrieval
- Verified model/runtime installer and configuration-preservation tests
- Strict offline enforcement for search, hosted inference, and first-use local model downloads
- Director-level executive brief, industry boundaries, scale path, system card, control matrix, risk register, and pilot scorecard
- Apache-2.0 license, public governance, security, privacy, contribution, conduct, and support policies
- Windows quality CI, CodeQL, Dependabot, CODEOWNERS, and issue/pull-request templates

### Changed

- Repositioned iBuddy as Sovereign AI iBuddy, a controlled-pilot reference implementation
- Made offline mode the default
- Renamed the per-message “Local only” option to “No web search” to describe its actual behavior
- Changed default web safe-search policy from off to moderate
