# Support

Sovereign AI iBuddy is a public reference implementation maintained on a best-effort basis. There is no production SLA, warranty, regulated-service support, or guarantee that a model/provider/dependency will remain available.

## Use the right route

| Need | Route |
|---|---|
| Reproducible defect | GitHub bug report |
| Scoped feature or governance improvement | GitHub feature request |
| Security vulnerability or exposed secret | Private process in [SECURITY.md](SECURITY.md) |
| Setup and development guidance | [README.md](README.md) and [DEVELOPMENT.md](DEVELOPMENT.md) |
| Architecture/scale question | [Scalability and sovereignty](docs/SCALABILITY_AND_SOVEREIGNTY.md) |
| Production compliance, legal, medical, financial, or regulatory interpretation | Your qualified organizational owner or adviser; not this project |

## Before opening an issue

- search existing issues;
- run the current `main` branch or latest release;
- remove all sensitive data;
- include OS, Python/Node versions, commit, configuration names without values, exact command, expected/actual behavior, and a minimal reproduction;
- attach logs only after reviewing and redacting paths, identifiers, prompts, tokens, keys, and business data.

## Scope boundary

The project can help with the code as published. It cannot accept operational responsibility for forks, model quality in a specific domain, customer/patient decisions, enterprise deployment, data authorization, provider terms, or local infrastructure.
